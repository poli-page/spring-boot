For the latest release notes, see [GitHub Releases](https://github.com/poli-page/spring-boot/releases).

## Versioning

The starters share their major.minor with the Poli Page API: starter `0.13.x` talks to API `0.13` and requires `page.poli:sdk` `0.13.x`. Patch numbers are free. The three artifacts are released together, under one version.
