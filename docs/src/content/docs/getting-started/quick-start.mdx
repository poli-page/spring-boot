With the starter on the classpath and `poli-page.api-key` set, a controller renders a PDF in a few lines. The starter provides the `PoliPageClient` bean and the `PoliPageResponses` helper. You inject both through the constructor.

## Add the starter and the key

Add the dependency and the key as in [Install](../install/). The only configuration you need is:

```yaml
# application.yml
poli-page:
  api-key: ${POLI_PAGE_API_KEY}
```

## Render from a controller

Call the SDK through `client.render()`, then hand the result to `PoliPageResponses`. `bytes(pdf, filename)` answers a `ResponseEntity<byte[]>` with `Content-Type: application/pdf`, an RFC 5987 `Content-Disposition`, `Cache-Control: private, no-store` and `X-Content-Type-Options: nosniff`. A reactive app uses `PoliPageReactiveResponses` instead: see [WebFlux](../../concepts/webflux/).

The key selects the environment whose published copy of the project is rendered. The input carries no version. Every Poli Page org comes with the `getting-started` project and its `welcome` template in `sandbox`, so you can swap `billing` and `invoice` for `getting-started` and `welcome` to try it with a `pp_sandbox_…` key.

## Example

```java
package com.example.billing;

import java.util.Map;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RestController;
import page.poli.sdk.PoliPageClient;
import page.poli.sdk.input.RenderInput;
import page.poli.sdk.spring.web.PoliPageResponses;

@RestController
public class InvoiceController {

    private final PoliPageClient client;
    private final PoliPageResponses responses;

    public InvoiceController(PoliPageClient client, PoliPageResponses responses) {
        this.client = client;
        this.responses = responses;
    }

    @GetMapping("/invoice/{id}.pdf")
    public ResponseEntity<byte[]> show(@PathVariable String id) {
        byte[] pdf = client.render().pdf(RenderInput.builder()
            .project("billing")
            .template("invoice")
            .data(Map.of("invoiceNumber", id))
            .build());
        return responses.bytes(pdf, "invoice-" + id + ".pdf");
    }
}
```
